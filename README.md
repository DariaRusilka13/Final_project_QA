# Автотест API Яндекс.Самокат

Проверяет, что созданный заказ можно получить по номеру трека.

## Что проверяет тест
1. Создание заказа (код ответа 201).
2. Получение заказа по треку (код ответа 200).

## Подготовка и запуск
- Для запуска тестов должны быть установлены пакеты pytest и requests
- В `configuration.py` указать актуальный адрес стенда в `URL_SERVICE`.
- Запуск всех тестов выполняется командой pytest
